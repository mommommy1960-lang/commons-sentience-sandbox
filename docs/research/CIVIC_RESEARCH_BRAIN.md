# Civic Research Brain

This prototype is a transparent work-loop, not a claim of consciousness. It
makes self-critique explicit and repeatable.

## Start a session

python tools/civic_research_brain.py create --question "How should we improve the sandbox?"
python tools/civic_research_brain.py prompts

## Six internal passes

1. Builder: propose an improvement.
2. Breaker: attack the proposal.
3. Repairer: design the smallest repair.
4. Verifier: define a decisive test.
5. Market reality: identify a real user and adoption evidence.
6. Physical reality: identify measurements required before physical claims.

Each pass must preserve the distinction between an idea, an implemented change,
and independently verified evidence. The system is intentionally not allowed to
treat enthusiasm, simulation output, or a passing thought experiment as proof.
