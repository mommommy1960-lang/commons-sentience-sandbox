# Civic Continuum Proof Package

This directory turns the Civic Continuum paradigm into five bounded, reviewable proofs.

1. [Curriculum proof](./01-curriculum-proof.md)
2. [Product proof](./02-product-proof.md)
3. [Governance proof](./03-governance-proof.md)
4. [Revenue proof](./04-revenue-proof.md)
5. [Evidence and transparency proof](./05-evidence-and-transparency-proof.md)

This package is intentionally on a separate branch. It does not modify `main` or PR #32. It should be reviewed for privacy, intellectual property, safety, rights, and unsupported claims before a pull request is opened.

The governing principle is simple: build a small, honest version of Civic Continuum now, measure what happens, correct it, and expand only when evidence and capacity justify expansion.
