# Claim Evidence Ledger

## Evidence classes

- **E0 Idea**: an articulated possibility.
- **E1 Specification**: interfaces, assumptions, and intended behavior are defined.
- **E2 Executable test**: a reproducible test and pass or fail rule exist.
- **E3 Reproduced software result**: committed software passes in a documented environment.
- **E4 Physical or human-subject result**: protocol, data, approvals, uncertainty, and provenance are available.
- **E5 Independent replication**: an unaffiliated party reproduces the result.

## Rule

No claim advances because it sounds compelling. It advances only when the next evidence class is satisfied and the underlying artifacts are public or available for qualified review.
