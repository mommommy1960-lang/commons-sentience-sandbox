## Proposed ways to try and buy
These are the intended product tiers; hosted end-to-end readiness is not yet verified.

1. **Five-minute public demo — free, no account.** A guided interactive sandbox using fictional data: an allowed action, a blocked overreach, access revocation, and an audit summary. Reset available.
2. **One-hour free trial — limited interactive sandbox.** Real interactive use for up to 60 minutes with clear limits, an actual expiry, reset, and fictional/sample data. The current hosted trial must be implemented and verified before we advertise it as available.
3. **$25 Founding Review — bounded human service.** A one-time, limited review with clearly stated deliverables, delivery window, exclusions, contact path, and refund/cancellation terms. It is not a recurring software subscription.
4. **Future paid software subscription.** Separate decision; do not activate until price, billing interval, cancellation, privacy/security scope, support, payment confirmation, quotas, and refunds have been tested.

## Demo verification standard
The source code includes school, banking, nonprofit donor/member, and customer-support scenarios. Source review is not the same as a live hosted test. We will mark each test with its evidence type: source inspection, local automated test, or hosted browser test. A scenario is not described as production-integrated when identities, alerts, data, or workflow actions are simulated.

We want supporters to understand the purpose of any funding request and see how funds are accounted for. Before a payment link is published, the project must identify the legal recipient and status, clarify whether funds are a donation, grant, loan, contribution, or payment for services, state intended uses and any restrictions, document receipt/refund handling, account for processor fees, and establish periodic income/expense updates. We will not promise tax deductibility unless it has been confirmed.

For now, review the public budget and contact the project through the verified public contact route. Do not send money to a personal or unverified destination based only on this planning document.
