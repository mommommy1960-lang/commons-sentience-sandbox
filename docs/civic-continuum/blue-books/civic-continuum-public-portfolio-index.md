# Civic Continuum Public Portfolio Index

## Purpose

Civic Continuum is a staged program for building accountable services, software,
education, research, and physical prototypes that people can inspect, use, correct,
and afford. This index is a public navigation document. It describes the work without
publishing private drawings, credentials, supplier material, medical procedures,
security-sensitive implementation details, or patent-sensitive technical cores.

## Evidence rule

Every project carries separate labels for concept, paper specification, software
prototype, bench prototype, validated system, pilot, and product. A document, image,
simulation, timestamp, or DOI establishes provenance or communication; it does not by
itself establish physical feasibility, patent rights, legal enforceability, safety,
certification, or market demand.

## How work advances

1. Preserve the exact source, creator, version, and public or private status.
2. Define the user, problem, intended function, non-claims, and prohibited uses.
3. Separate established mechanisms from hypotheses.
4. Write requirements, assumptions, hazards, costs, and failure modes.
5. Define reproducible tests with pass, fail, and stop criteria.
6. Run the smallest safe test and preserve negative results.
7. Obtain independent technical, legal, safety, rights, or regulatory review as needed.
8. Build only the smallest bounded prototype.
9. Pilot with written consent, support, correction, refund, and recall procedures.
10. Publish truthful evidence and update the status when the evidence changes.

## Public protection boundary

Public materials may contain the mission, high-level architecture, evidence labels,
test status, citations, limitations, and sanitized product briefs. Private materials
must contain credentials, keys, personal information, supplier quotes, NDA text,
unreleased drawings, detailed security architecture, medical or biological procedures,
and patent-sensitive implementation details.

## Current public claim

Civic Continuum is a developing portfolio of accountable services, software,
curricula, research programs, governance frameworks, and physical invention studies.
It is not yet a civilization-scale replacement or a portfolio of production-ready
devices. Its credibility will be earned through working artifacts, independent review,
transparent failures, and useful outcomes.
