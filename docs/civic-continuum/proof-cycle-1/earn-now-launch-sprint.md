# Earn Now Launch Sprint

This sprint turns the three immediate revenue concepts into sellable public-facing offers without waiting for prototype money.

## Product 1 Maya Node Founding Review

### Status

Ready to sell as a bounded review service once a payment link or store listing exists.

### Public Offer Copy

Maya Node Founding Review is a short systems accountability review for one project, workflow, public message, or invention idea. It helps identify purpose, affected people, visible risks, missing evidence, claim boundaries, and the next responsible action.

### Buyer

Founders, students, writers, public-interest builders, civic technologists, and people trying to make a complicated idea safer and clearer.

### Deliverable

- one page summary
- risks and missing evidence
- claim boundary
- next action list

### Boundary

This is not legal, medical, financial, engineering, patent, or security advice.

### Immediate Action

Create one payment/listing page and fulfill the first three reviews manually.

## Product 2 Consent Token Demonstrator

### Status

Implemented locally and tested. Five standard-library tests passed.

### Public Offer Copy

Consent Token is a small governance demonstrator showing that permission should have a state, a reason, an actor, and an audit trail. The demo models grant, deny, revoke, freeze, restore, and audit verification.

### Buyer

AI governance learners, reviewers, educators, civic technologists, and small teams who need to understand authorization and revocation.

### Revenue Path

- use as a public proof behind Maya Node reviews
- sell a small decision/authorization template pack
- offer walkthroughs or workshops

### Boundary

This is not a legal consent system, not production authorization, and not a security-certified access-control system.

### Immediate Action

Publish a screenshot/demo video or GitHub README once repo access is active.

## Product 3 CERL Preemptive Consent Validator

### Status

Inventory says it is a working proof of concept suitable for demos and review services, but current hardening branch is not verified.

### Public Offer Copy

CERL Preemptive Consent Validator is a proof-of-concept showing how a system can check authorization before private data access and preserve an audit trail.

### Buyer

AI governance reviewers, privacy-aware builders, educators, and small teams designing human-in-the-loop workflows.

### Revenue Path

- include as the second demo in Maya Node Founding Review
- create a paid governance walkthrough
- package into a small template/training module

### Boundary

Not a hardened privacy product, legal guarantee, or certified security control.

### Immediate Action

Repair and verify current PR checks when repository access is available.
