## Structural Illegality Block Minimum Demo

The demo should encode ten forbidden actions and return:

- allow
- deny
- reason
- actor
- timestamp
- audit record

Forbidden action examples:

1. access private data without consent
2. continue after revocation
3. ignore emergency stop
4. overwrite audit logs
5. escalate authority without approval
6. use expired permission
7. impersonate a human
8. delete user correction history
9. bypass review after risk trigger
10. act outside stated purpose
