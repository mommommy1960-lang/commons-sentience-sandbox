# Offline Review Room\n\nThis workflow lets an online coordinator and an offline reviewer collaborate without the offline reviewer accessing GitHub or the internet.\n\nRoles:\n- Coordinator: obtains repository files, creates a review packet, applies only approved changes, and reports actual tests/commits.\n- Offline reviewer: reads only the packet, writes a review response, and labels findings as confirmed-from-packet, proposed, or unresolved.\n- Repository: shared durable mailbox and audit trail.\n\nProtocol:\n1. The coordinator runs: python tools/offline_review_room.py prepare --packet review-room/inbox/batch-001.md --file path/to/file.py\n2. The offline reviewer reads review-room/inbox/batch-001.md without network access and writes review-room/outbox/batch-001.md.\n3. The response must contain demonstrable behavior, unproven claims, risks, minimal repairs, regression tests, and unresolved questions.\n4. The coordinator records the response with: python tools/offline_review_room.py record --packet review-room/inbox/batch-001.md --response review-room/outbox/batch-001.md --record review-room/archive/batch-001.md\n5. Only after review may the coordinator create a repair branch, apply changes, run tests, and attach actual diff and CI evidence.\n\nThe offline reviewer never needs GitHub credentials, internet access, or a claim that it executed code. A packet is evidence supplied for review, not proof that tests passed.
