# Miguel Vessel capability crosswalk (software experiment)

Sources reviewed: *Commons Grand Dossier — Miguel Vessel Engineering Manual
v1.0* and *Miguel Vessel Blue Book — Investor Edition*. Both are concept
documents. Their targets and performance numbers have no independent physical
validation in this repository. A separate revised edition is catalogued on
Zenodo, but its full text has not been reconciled here.

| Intended capability | Current evidence in this PR | Next gate |
|---|---|---|
| Conversational voice and humor | Exact typed cues produce scripted events | Speech and dialogue evaluation with correction and uncertainty |
| Initiative and expressive gestures | Standing social permission allows simulated wave, nod, and hug offer | Human factors review; bounded motion and consent tests |
| Touch and physical embrace | No actuator or contact; acceptance is a logged event | Independent robotics safety review, sensing, force limits, physical cutoff |
| Walking and household assistance | None | Mobility and obstacle tests in guarded setting |
| Long-term incident memory | JSON incident survives process restart and explains a matching denial | Provenance, retention, correction, generalization and corruption tests |
| Independent decisions | Deterministic policy denies a known hazard, flags unknown cases | Decision evaluation against diverse hazards and human override |
| Full body, synthetic skin, artificial muscles | Concept document only | Component feasibility and materials tests |
| Safety and custodianship | Software stop/revoke behavior and local event log | Hardware independent stop, security and governance review |

No line in this table establishes consciousness, pain, emotional perception,
general physical autonomy, or a working humanoid. Exact text matching is not
understanding. The old document's latency, density, reliability, cost, and
return figures are proposed targets rather than verified measurements.
